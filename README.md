# 🐰 말랑숫자 동물마을

파스텔톤 동물 친구들과 함께 숫자를 차곡차곡 쌓는 협동/경쟁 카드 게임입니다.
별도 설치 없이 브라우저에서 바로 즐길 수 있는 순수 HTML/CSS/JavaScript 웹 게임이에요.

- 🐰 토끼의 등산로: 점점 큰 숫자로 올라가요
- 🐹 두더지의 땅굴: 점점 작은 숫자로 내려가요
- 손패를 모두 내려놓으면 다 함께(또는 혼자) 승리!

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 🟢 일반 협력 모드 | 숫자 2~99, 확장팩(익스트림/화난 식빵/조커/레인지) 자유 조합 |
| 🟡 퀵 앤 이지 | 숫자 1~50, 젤리 색상이 같으면 대소 무시하고 역행 가능 |
| 🔵 페이스 투 페이스 | 2인 전용 경쟁 모드, 상대 더미에 유리한 카드를 선물할 수 있어요 |

싱글 플레이는 최대 5명의 AI 동물 친구와 함께할 수 있고, AI는 현재 더미와 손패 차이를 계산해
가장 안전한 카드를 우선 내는 그리디 엔진으로 동작합니다.

## 로컬에서 실행하기

빌드 과정이 없습니다. 정적 파일 서버만 있으면 됩니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## GitHub Pages로 배포하기

1. 저장소 Settings → Pages → Source에서 배포할 브랜치(예: `main`)와 루트(`/`)를 선택
2. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속 가능

## 멀티플레이(Firebase) 설정하기

방 만들기·참가하기 기능은 Firebase Realtime Database를 사용합니다. 설정 전까지는
멀티플레이 버튼을 눌러도 안내 메시지만 뜨고 비활성 상태로 유지돼요.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴에서 **Realtime Database**를 생성합니다. (테스트 모드로 시작해도 됩니다. 운영 시에는 보안 규칙을 반드시 설정하세요.)
3. 프로젝트 설정 → 일반 탭 → "내 앱"에서 웹 앱을 추가하고 SDK 설정 값을 확인합니다.
4. `js/firebase-config.js` 파일을 열어 아래 값을 채워 넣습니다.

```js
export const firebaseConfig = {
  apiKey: '...',
  authDomain: '...',
  databaseURL: '...',   // Realtime Database 사용에 필수
  projectId: '...',
  storageBucket: '...',
  messagingSenderId: '...',
  appId: '...',
};
```

5. 저장 후 다시 로드하면 방 만들기/참가하기 버튼이 활성화됩니다.

### 멀티플레이 동작 방식

- 방을 만든 플레이어(호스트)가 게임 상태를 계산하는 권위자 역할을 합니다.
- 참가자는 자신의 행동(카드 내기/차례 마치기)을 호스트에게 전달하고, 호스트가 검증 후
  최신 상태를 모두에게 다시 배포합니다.
- 방 인원이 부족하면 호스트가 설정한 인원만큼 AI 동물 친구가 빈 자리를 채워줍니다(하이브리드 매칭).

## 프로젝트 구조

```
index.html          화면 구조 (메뉴 / 설정 / 로비 / 게임 / 결과)
manifest.json        PWA 매니페스트
service-worker.js    오프라인 캐싱용 서비스 워커
icons/               PWA 아이콘 (icon.svg 원본 + PNG 여러 사이즈)
css/style.css        파스텔 테마 스타일
js/constants.js      카드 데이터 및 상수
js/deck.js           덱 생성 · 셔플
js/rules.js          규칙 판정 함수 (순수 함수)
js/game.js           게임 상태 머신
js/ai.js             그리디 AI 엔진
js/ui.js             화면 렌더링
js/signals.js        이모지 신호등
js/main.js           화면 전환 및 이벤트 처리
js/net.js            Firebase 멀티플레이 연동
js/firebase-config.js Firebase 설정 (직접 채워야 함)
```

## 소통 방식

자유 채팅 대신 미리 정해진 이모지 신호 템플릿만 사용할 수 있어요. 내 캐릭터(아바타)를 누르면
신호 선택 팝업이 뜨고, 여기서 "⬆️ 낼 카드 있어!", "나 높은 카드 많아! 🔼", 순수 이모지 반응 등을
골라 말풍선으로 보낼 수 있습니다. 정확한 숫자는 말할 수 없어요.

## 게임판 살펴보기

- 더미는 화살표(⬆️/⬇️)로 방향만 표시해 화면을 한눈에 볼 수 있게 했어요. 더미 왼쪽 위 🔍 아이콘을
  누르면 그 더미에 놓인 카드 전체를 볼 수 있습니다.
- 상단의 덱 카운터를 누르면 아직 나오지 않은 카드를 10단위로 정리해서 보여줘요. (페이스 투 페이스
  모드에서는 상대 덱의 카드 내용은 비공개, 장수만 보여줍니다.)
- 내 차례에는 낼 수 있는 카드가 초록 테두리로 강조되고, 필요한 만큼 다 냈다면 "차례 마치기" 버튼이
  반짝여요. ±10 되돌리기나 색상 일치로만 낼 수 있는 카드는 왼쪽 아래에 작은 뱃지가 붙습니다.

## PWA로 설치하기

`manifest.json`과 서비스 워커가 포함되어 있어 모바일/데스크톱 브라우저에서 "홈 화면에 추가" 또는
"앱 설치"로 아이콘을 만들어 둘 수 있어요. 정적 파일이 캐시되어 오프라인에서도 싱글 플레이가
가능합니다(멀티플레이는 인터넷 연결이 필요해요). GitHub Pages 등 HTTPS 환경에서 배포해야 정상
동작합니다.
